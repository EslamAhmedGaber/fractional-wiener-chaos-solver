# CosChaos — cosine-coordinate fractional Wiener chaos solver (release v1.1.3)

CosChaos solves stochastic differential equations driven by fractional Brownian motion (Hurst index 1/2 <= H < 1,
Wick-type noise). It returns the finite chaos approximation, X_{J,p}(t) = sum_alpha c_alpha(t) Phi_alpha(xi), a polynomial in
J independent standard Gaussian coordinates xi of the fBm path, with deterministic coefficients from one coefficient
solve. From this output:

- the pathwise solution on a given path (evaluate at the coordinates of that path),
- the moments of any order (from the coefficients),
- quantiles, densities and event probabilities (sample xi; no new solve).

The cosine and half-integer sine Gram matrices are in closed form through 1F1(2H-1; 2H; ix).

Manuscript: "CosChaos: a cosine Wiener chaos solver for stochastic differential equations driven by fractional
Brownian motion" (E. Ahmed, M. A. El-Beltagy, A. Etman,
S. M. Elnady; manuscript prepared for Chaos, Solitons & Fractals).

## Layout
- `solver/` — `hwc.py` (CosChaos: basis, Gram matrix, coefficient law, memory branch), `hfc.py` (closed-form Gram
  entries), `examples_v6.py` (example equations and reference formulas).
- `scripts/` — experiment drivers, table and figure generators (see RELEASE_NOTES_v1.1.3.md).
- `evidence/` — JSON results from which every table, number macro and figure is generated.

## Reproduce (Python 3 with numpy, scipy, mpmath, matplotlib; numba for the round5 scripts)
    python scripts/round3b_workprecision.py      # work-precision against FWHE time stepping
    python scripts/round3c_fullsolution.py       # pathwise solutions and laws
    python scripts/round4_probability.py         # event probability of the cubic model (Monte Carlo + CosChaos)
    python scripts/round4_probability_highdeg.py # degree five for the event probability
    python scripts/round5_mc_reference.py 0 4    # far-tail Monte Carlo reference, worker 0 of 4 (run workers 0..3), then
    python scripts/round5_mc_summary.py          #   -> evidence/round5/P5_mc_reference.json
    python scripts/round5_modeshare.py           # variance shares of the coordinates (choice of the index set)
    python scripts/round5_ladder.py AN13_28c     # CosChaos on an anisotropic index set (names in evidence/round5/ladder_configs.json;
                                                 #   LADDER_METHOD=Radau for p0 >= 16, LADDER_OUT, LADDER_H)
    python scripts/round5_bigsample.py AN13_28c  # 10^7 samples of xi for a converged set
    python scripts/round3b_tables.py; python scripts/round3c_tables.py; python scripts/round4_tables.py; python scripts/round5_tables.py
    python scripts/round3_final_figures.py; python scripts/round5_figure.py
Seeds are fixed in each script. Monte Carlo runs with 10^6 paths take a few minutes per Hurst index; the 2x10^7-path
reference takes about 3x10^3 s of CPU time per Hurst index. The per-batch sample files (npz) of the round5 runs are not
included (about 0.4 GB); they are regenerated by the scripts above, and the JSON summaries in `evidence/round5/` are the
values used in the paper. All figures can be regenerated from `evidence/` alone.

## Index sets (Round 5)
Besides total degree {|alpha| <= p}, `round5_ladder.py` accepts the anisotropic sets
A_J(p_0, ..., p_{J-1}) = {alpha : sum_k alpha_k / p_k <= 1}. Choose the profile from the variance shares of the
coordinates in the degree-one solution (`round5_modeshare.py`): a high degree in xi_0 = T^{-H} B_H(T) at large H, more
modes of low degree near H = 1/2, degree 2 for the trailing coordinates.

## Version and reproducibility
The current solver is in solver/. evidence/solver_snapshot/ retains the older benchmark engine
for releases v1.1.0--v1.1.2; it is not the current entry point.
Cite v1.1.3 through CITATION.cff.
Release: https://github.com/EslamAhmedGaber/fractional-wiener-chaos-solver/releases/tag/v1.1.3

At finite mode count and chaos degree, solution paths, moments and laws are approximations.
Sampling the polynomial adds sampling uncertainty to event probabilities and quantiles.
Install with: python -m pip install -r requirements.txt
The round5 memory-usage reporter uses Windows APIs; these experiment scripts were run on Windows.
Current-engine checks are described in docs/RELEASE_VALIDATION_v1.1.3.md.
scripts/verify_release.py checks repository hashes and historical regression cases.

For all manuscript figures, run scripts/make_figures_v5.py for the inherited panels,
then scripts/round3_final_figures.py and scripts/round5_figure.py for updated panels.
Required legacy plotted coordinates are in figure_design/legacy_extracts/.
The release ZIP includes these dependencies and the current solver and evidence.
Original staging hashes are in docs/STAGING_MANIFEST_v1.1.3.json;
MANIFEST_SHA256.json records the integrated repository.
