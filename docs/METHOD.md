# Method and equation-driven interface

For one scalar standard fractional Brownian motion on [0,T], 1/2 <= H < 1, solve
dX = F(t,X) dt + D(t,X) diamond dB_H with deterministic X(0).
The diamond denotes the Wick/Skorohod interpretation. Ordinary drift nonlinearities remain ordinary products.

## The same six steps for each admissible equation

1. Supply F, D, X0, H, T, J and p. Check the supported equation class and computational budget.
2. Use h_0 = 1/sqrt(T), h_k(t) = sqrt(2/T) cos(k*pi*t/T). Form G_ij = E[Z_i Z_j], where Z_i = integral h_i dB_H, from the closed-form Gram implementation. Compute G = L L^T. The optional sine family has half-integer frequencies.
3. Set xi = L^{-1} Z and ell(t) = L^T h(t). Write X_{J,p} = sum c_alpha(t) Phi_alpha(xi), where Phi_alpha is the product of normalized probabilists' Hermite polynomials.
4. Compute P_alpha[F] = E[F(t,X_{J,p}) Phi_alpha] and similarly for D. Then
   dc_alpha/dt = P_alpha[F] + sum_{j:alpha_j>0} sqrt(alpha_j) ell_j(t) P_{alpha-e_j}[D].
   Initialize c_0(0)=X0 and all other coefficients to zero.
5. Integrate this deterministic coefficient system. E[X_{J,p}]=c_0 and Cov[X_{J,p}]=sum_{alpha != 0} c_alpha c_alpha^T.
6. Refine J at fixed p and p at fixed J. Use analytic or independent numerical references where available; refinement alone is not a certificate for a general nonlinear equation.

## Bases and scope

The integrands u=L^{-1}h are orthonormal in the fractional inner product. The time-driving functions ell=L^T h have a different role and are generally not orthonormal. The stochastic Hermite family is complete in the L2 space generated by the fBm; fixed J and finite p select a finite-dimensional approximation space.

For affine equations with H-independent model data, correlated-coordinate coefficient equations can be reused across H values; covariance is then evaluated using the appropriate G^H. Ordinary nonlinear products introduce H-dependent contractions. At H=1/2 the Gram matrix is the identity.

The scalar linear Caputo branch obtains the Green function from the equation's Laplace symbol internally. The caller supplies the memory coefficient and order, not a model-specific solution kernel.

## Implementation limits

Polynomial fields are supported through degree three. Callable fields use Gaussian reduction at p=1 and budgeted tensor Gauss-Hermite at higher degree. Multiple scalar drivers, H<1/2 and general nonlinear memory are not implemented. The large-angle pendulum and double-well failures in the recorded experiments remain limitations of the tested truncations.
