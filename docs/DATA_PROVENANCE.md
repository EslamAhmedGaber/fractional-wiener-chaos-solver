# Data provenance

All solver model inputs are synthetic. JSON files record numerical experiments.

The supplementary temperature illustration uses the northern-hemisphere temperature series distributed with R package longmemo (Beran and collaborators), as cited in the manuscript. The release retains derived plot arrays and computed outputs. It does not claim ownership of the source observational record. Source: https://CRAN.R-project.org/package=longmemo

The legacy_extracts directory stores coordinates of previously plotted curves. These are archived comparison inputs, not new simulations. SOURCE_PROVENANCE.json lists source hashes. Frozen benchmark inputs remain separate from fresh outputs under runs/.

No author correspondence, reviewer comments or authentication data are included.
